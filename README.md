# KORSAKOV — аналитика социальных сетей

Личный кабинет для сбора статистики **ВКонтакте**, **Telegram** и **MAX**. Знак KORSAKOV — очки из айдентики сервиса; на главной странице представлена цитата Семёна Николаевича Корсакова об интеллектуальных машинах. Сервис работает без сторонних Python-библиотек, хранит токены только на сервере и продолжает собирать публичные показатели без API-ключей.

## Запуск

Требуется Python 3.9+.

```bash
cp .env.example .env
python3 server.py
```

Откройте [http://localhost:8080](http://localhost:8080). Публичная страница показывает возможности сервиса; кнопки **Создать аккаунт** и **Войти** открывают формы регистрации и входа. Можно зарегистрировать несколько аккаунтов. Существующий аккаунт `necit0186@gmail.com` автоматически получает роль администратора; его прежние подключения VK, Telegram и MAX и историю сервис переносит в отдельную папку. Пароль остаётся прежним. Исходные файлы сохраняются как резервная копия. Если установка пустая, администратором становится первый зарегистрированный пользователь.

Новый пользователь сразу получает первую папку с тремя площадками — VK, Telegram и MAX. Ссылки и токены он заполняет сам. Каждая папка хранит свои подключения, токены, снимки и события. Выберите папку в верхней части кабинета для просмотра её статистики. Папку можно переименовать кнопкой рядом с выбором папки или в разделе **Мои папки**; подключения и история при этом сохраняются. Дополнительную папку можно запросить через кнопку **Добавить папку**; способ оплаты пока не подключён. Премиум существует как административная функция и не упоминается в обычном кабинете до выдачи: он увеличивает лимит до **трёх папок всего**. Администратор может отдельно увеличить лимит дополнительными папками. Если премиум снят или квота уменьшена, существующие папки не удаляются, но создавать новые сверх лимита нельзя.

Раздел **Администратор** открывается администратору при входе и доступен только этой роли. Здесь отображаются пользователи, их папки и подключённые проекты. Можно выдать или снять премиум, изменить количество дополнительных папок, заблокировать аккаунт, папку или отдельный проект. Блокировка прекращает доступ и сбор данных; разблокировка возвращает доступ. Администратор не видит токены пользователей.

## Личный кабинет

Откройте раздел **Личный кабинет** и нажмите **Подключить API** у нужной площадки. Для каждой сети доступны два уровня подключения:

1. **Публичный сбор** — достаточно вставить ссылку на канал или сообщество. Токен не требуется.
2. **Официальный API и webhook** — добавляет закрытые административные показатели и получение новых событий сразу после публикации.

Форма не показывает сохранённый токен повторно. Аккаунты хранятся в `data/users.json`, список папок — в `data/folders.json`, настройки и история каждой папки — в `data/folders/<id>/`. Секретные файлы имеют права `0600` и исключены из Git. Старые `data/account.json`, `data/connections.json`, `data/runtime.json` остаются резервной копией после миграции.

### ВКонтакте

1. Скопируйте полный адрес своего сообщества, например `https://vk.ru/my_community`.
2. В сообществе откройте **Управление → Настройки → Основная информация** и скопируйте числовой ID без минуса.
3. Для `stats.get` нужен токен пользователя-администратора с доступами `groups` и `stats`. Сервис никогда не запрашивает пароль VK.
4. Для мгновенных событий откройте **Управление → Дополнительно → Работа с API → Callback API**.
5. Скопируйте из мастера выбранной папки URL `/webhooks/vk/<id-папки>` и секретный ключ в соответствующие поля VK.
6. Скопируйте показанную VK строку подтверждения обратно в кабинет, сохраните форму и нажмите **Подтвердить** во VK.
7. На вкладке **Типы событий** включите новые записи, комментарии, вступления и выходы.

Официальная документация: [Callback API VK](https://dev.vk.com/ru/api/callback/getting-started).

### Telegram

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и создайте бота.
2. Скопируйте выданный API token вида `123456789:AA...` в кабинет.
3. Откройте **Управление каналом → Администраторы → Добавить администратора**, добавьте бота и разрешите ему видеть/публиковать сообщения.
4. Для публичного канала вставьте ссылку `https://t.me/name` и ID `@name`. Для частного канала нужен числовой ID вида `-100...`.
 5. Сохраните форму и нажмите **Включить webhook Telegram**. Сервис вызовет официальный `setWebhook` и передаст защитный secret token. Для нескольких папок используйте отдельных ботов: Telegram поддерживает один webhook на токен бота.

Официальная документация: [Telegram Bot API — setWebhook](https://core.telegram.org/bots/api#setwebhook).

### MAX

1. Создайте верифицированный профиль организации, ИП или самозанятого на [платформе MAX для партнёров](https://business.max.ru/self).
2. В разделе **Чат-боты** создайте бота. Затем выберите его, нажмите **⋮ → Настройки** и значок копирования рядом с токеном.
3. Вставьте токен и ссылку канала в кабинет, сохраните форму и нажмите **Включить webhook MAX**.
4. Добавьте бота администратором канала. Событие `bot_added` передаст сервису `chat_id` автоматически. Если ID уже известен, его можно указать сразу.

Официальная документация: [создание бота](https://dev.max.ru/docs/chatbots/bots-create/create), [получение chat_id](https://dev.max.ru/docs-api/use-cases/getting-chat-id), [webhook](https://dev.max.ru/docs-api/methods/POST/subscriptions).

## Реальное время

Webhook не работает на `localhost`: серверы социальных сетей должны иметь возможность отправлять запросы на публичный адрес. После развёртывания задайте в `.env`:

```dotenv
HOST=0.0.0.0
PUBLIC_BASE_URL=https://analytics.example.ru
```

Адрес должен использовать HTTPS с доверенным сертификатом. Для MAX webhook должен быть доступен на стандартном порту 443. После перезапуска сервиса готовые URL появятся в мастере подключения.

После миграции заново настройте адрес VK Callback API и зарегистрируйте webhook Telegram и MAX в мастере: адреса теперь включают ID папки. Webhook доставляет новые события сразу, но некоторые агрегированные показатели — например просмотры и полный охват — сами площадки пересчитывают с задержкой. Они дополнительно обновляются периодической синхронизацией (`SYNC_INTERVAL_MINUTES`, по умолчанию 30 минут).

## История по годам

В разделе **Отчёты** доступны отдельные таблицы для текущего и выбранного прошедшего года. В каждой можно переключить разбивку **по месяцам / по кварталам**. Аудитория берётся из последнего сохранённого замера периода, изменение — из первого и последнего дней с замерами. Публикации, просмотры и реакции считаются по уникальным зафиксированным постам. Отсутствующие периоды обозначаются прочерком, а не нулём. Данные разделены по папкам и площадкам; заблокированные проекты не отображаются.

Сервис сохраняет ежедневные замеры и архив обнаруженных публикаций для будущих годовых отчётов. Ранее сохранённые замеры также используются, пока доступны в файле. Для прошедших лет VK при наличии токена администратора и ID сообщества можно нажать **Загрузить историю VK**: официальный `stats.get` вернёт помесячный охват, который отображается отдельно от просмотров публикаций. VK может предоставить неполный архив. Bot API Telegram и MAX не предоставляют произвольную архивную статистику аудитории: для этих площадок показываются только фактически накопленные сервисом данные.

## API сервиса

- `GET /api/auth/status` — состояние первого запуска и авторизации.
- `POST /api/auth/register`, `/api/auth/login`, `/api/auth/logout` — регистрация и вход.
- `GET /api/folders`, `POST /api/folders/create`, `POST /api/folders/rename` — список, создание и переименование собственных папок (`folder_id`, `name`).
- `GET /api/dashboard?folder_id=<id>&period=30` — данные выбранной папки (требует входа).
- `GET /api/connections?folder_id=<id>`, `/api/cabinet?folder_id=<id>` — безопасные настройки без API-токенов.
- `POST /api/connections/save`, `/api/connections/webhook`, `/api/sync` — передайте `folder_id` в JSON-теле запроса.
- `GET /api/history/report?folder_id=<id>&year=2025&grouping=month|quarter` — годовой отчёт.
- `POST /api/history/backfill` — загрузить архив VK, тело: `{"folder_id":"<id>","year":2025}`.
- `GET /api/admin`, `POST /api/admin/update` — управление доступом (только администратор).
- `POST /webhooks/vk/<id>`, `/webhooks/telegram/<id>`, `/webhooks/max/<id>` — защищённые точки приёма событий папки.
- `GET /api/health` — проверка работоспособности без авторизации.

История снимков и входящие события сохраняются отдельно для каждой папки. Историческая динамика начинает строиться после нескольких замеров; официальные API не всегда отдают прошлую статистику задним числом.
